# 全球主要出海目标市场商品准入资质与强制认证矩阵

> 跨境出海“合规先行，防患未然”。货物到达目的港海关前，若缺少法定强制认证、产品安全标签或授权代表，海关将直接扣押、责令退运甚至就地销毁！  
> 本手册汇总欧美英日主流电商平台与海关的法定准入基准。

---

## 一、 欧盟市场（EU）准入强制资质与 2024 GPSR 新规

### 1. 欧盟通用产品安全法规（GPSR - General Product Safety Regulation）
- **生效时间**：**2024 年 12 月 13 日起强制执行**（所有进入欧盟市场的非食品消费品必须满足）。
- **三大核心红线（缺一不可）**：
  1. **欧盟负责人（EU Responsible Person / 欧代）**：产品必须指定在欧盟境内的法人实体作为合规责任人。
  2. **产品与包装标签合规**：
     - 必须印制欧盟负责人的名称、注册商号、邮政地址、电子邮箱/网址；
     - 必须印制制造商的名称、地址；
     - 必须有产品类型、批次、序列号以便溯源；
     - 必须提供销售目的国官方语言的警告说明书及安全信息。
  3. **合规技术文件（Technical Documentation）**：必须备齐 DoC（欧盟符合性声明）及第三方检测报告，保存期至少 10 年。
- *平台联动*：亚马逊、Temu、AliExpress、SHEIN 均已强制执行 GPSR 上传，无欧代和标签的产品直接下架屏蔽。

### 2. CE 标志与关键指令（适用电子电气、玩具、机械、建材）
- **LVD 低电压指令（2014/35/EU）**：交流 50~1000V / 直流 75~1500V 的家用电器、照明设备等电气安全。
- **EMC 电磁兼容指令（2014/30/EU）**：所有可能产生电磁干扰或受干扰的电子设备。
- **RED 无线电设备指令（2014/53/EU）**：带蓝牙、Wi-Fi、2.4G/5G 射频发射功能的所有智能硬件。
- **RoHS 2.0（2011/65/EU 及修订指令 2015/863）**：电子电气产品限制使用铅、汞、镉、六价铬、多溴联苯、邻苯二甲酸酯等 10 种有害物质。
- **玩具安全指令（2009/48/EC）**：14 岁以下儿童玩具必须满足 EN71 检测及带有 CE 标志。

### 3. 环保与生产者责任延伸（EPR）
- **WEEE（废弃电子电气设备指令）**：带插头或电池的电子产品必须注册当地回收税号（如德国 EAR）。
- **包装法（VerpackG）**：德国、法国等强制要求所有发往消费者的商品包装注册 EPR 并申报回收量。

## 二、 美国市场（US）海关监管与平台审核

### 1. FDA（美国食品药品监督管理局）准入
- **食品接触材料（FCM - Food Contact Materials）**：
  - 锅碗瓢盆、水杯、便当盒、咖啡机管道、硅胶厨具等必须通过 FDA 21 CFR 相关检测，证明在酸性/油脂环境下无有害化学溶出。
- **化妆品法规现代化法案（MoCRA）**：
  - 美妆护肤品生产设施必须在美国 FDA 注册，产品成分表必须列名登记，包装必须标注美国境内责任人联系方式。
- **医疗器械与激光辐射类**：
  - 血压计、体温枪、按摩仪（部分一类/二类器械）需 510(k) 认证或 FDA 设施列名；激光笔、激光雕刻机需满足 FDA CDRH 激光安全报告。

### 2. FCC（美国联邦通信委员会）电磁与无线认证
- **适用范围**：任何产生射频能量的电子设备。
- **三种合规形式**：
  - **SDoC（供应商符合性声明）**：适用于普通不带无线发射的有线电子产品（如显示器、移动硬盘、LED灯）；
  - **FCC ID（无线认证）**：带无线发射功能的产品（蓝牙音箱、Wi-Fi插座、无线麦克风、无人机等），必须在 FCC 官方数据库完成注册并生成专属 FCC ID 编码印在产品机身上。

### 3. 儿童产品 CPC 认证与 CPSIA 法案
- **适用对象**：12 岁及以下儿童使用的玩具、服装、婴儿用品、儿童饰品。
- **三大铁律**：
  1. 必须由 **CPSC（美国消费品安全委员会）认可的第三方独立实验室** 进行全项检测（ASTM F963、铅含量、邻苯二甲酸盐、小零件吞咽风险）；
  2. 制造商或进口商必须基于合格检测报告，签发 **CPC 证书（Children's Product Certificate）**；
  3. **追溯标签（Tracking Label）**：产品及包装上必须有永久性清晰标注（制造商名称、产地、生产批次、生产日期）。

### 4. UL / ETL 电气安全标准
- 亚马逊美国站对移动电源、笔记本电池、电热毯、插座、车载充电器等品类强制要求提供由 ISO 17025 资质实验室出具的 UL 标准测试报告（如 UL 2056、UL 1642、UL 62368 等），未提交的直接下架。

## 三、 英国（UK）与日本（JP）特色准入要求

### 1. 英国市场
- **UKCA 标志**：脱欧后替代 CE 标志的英国符合性评估标志（电子、机械、玩具等）。目前英国政府虽对部分通用消费品延长接受 CE 标志，但长期来看 UKCA 是法定义务。
- **英国合规负责人（UK Responsible Person）**：非英国本土卖家需指定英国境内合规代表。

### 2. 日本市场
- **PSE 认证（电气用品安全法）**：
  - **菱形 PSE（特定电气用品，116项高危品类）**：如交流适配器、锂离子蓄电池（能量密度≥400Wh/L）、插头插座，必须经由日本政府认可的第三方检验机构验厂并颁发证书。
  - **圆形 PSE（非特定电气用品，341项低危品类）**：如小家电、电风扇、LED灯泡，需符合日本标准并由企业做自我宣言。
- **TELEC 技适认证（无线电法）**：
  - 无线电发射设备（Wi-Fi、蓝牙、2.4GHz设备）必须获取技适标志（Giteki mark）及认证番号。
- **食品卫生法届出（厚生劳动省）**：
  - 接触食品的餐具、厨房小家电、6 岁以下婴儿玩具进境必须向日本海关提交进口届出验查。

## 四、 平台审核与海关查验必备单证清单对照

| 商品品类 | 目标市场 | 核心准入证书/报告 | 标签必备要素 |
|---|---|---|---|
| **带无线功能的 3C 数码** | 欧盟 | CE (RED/EMC/LVD) + RoHS + DoC | CE 标志、欧代信息、型号、频段参数 |
| | 美国 | FCC ID + 对应测试报告 | FCC ID 号码、FCC 警示声明 |
| **儿童玩具/母婴用品** | 美国 | CPSC 认可实验室报告 + CPC 证书 | 追溯标签（产地/日期/批号）、警示语 |
| | 欧盟 | EN71 检测报告 + CE (Toy) + DoC | CE 标志、0-3岁警告标、欧代信息 |
| **食品接触器具/餐具** | 美国 | FDA 21 CFR 测试报告 | 食品级标识、材质声明 |
| | 欧盟 | LFGB（德国）或 EU 1935/2004 检测报告 | 刀叉杯酒杯符号（食品接触标） |
| **移动电源/储能电源** | 美国 | UL 2056 / UL 1642 / UN38.3 | 额定容量、电压、安全警示、品牌型号 |
