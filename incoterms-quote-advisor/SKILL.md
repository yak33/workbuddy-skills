# 外贸报价与贸易术语防坑助手

> 帮助外贸业务员、跨境卖家与外贸工厂算清每一分利润，击碎贸易术语模糊陷阱，斩断指定货代敲竹杠，杜绝 DDP 倒贴亏本惨剧。

---

## 一、 这个技能做什么

外贸成交的核心在于“价格算得准、条款看得透、风险控得死”。本技能专为外贸实战打造：
1. **Incoterms 2020 权责与风险分界精算**：精准把关 11 种贸易术语（尤其 FOB、CIF、CIP、DAP、DDP、EXW）的交货点、风险转移点与费用分摊点，消除认知误区。
2. **DDP 倒贴防空警报**：全面排查目标国反倾销税、惩罚性关税、无 IOR 增值税无法抵扣、目的港滞期费等致命风险，给出最稳妥的替代谈判方案。
3. **FOB 指定货代敲竹杠防御 SOP**：提供起运港高额杂费抗辩谈判模版、货代资质审核与无单放货风险防范对策。
4. **工业级出口报价数学模型**：纠正出口退税算错误区，提供工厂出厂价、FOB 离岸底价、CIF 到岸价、DDP 完税交货价的逐级严谨换算。

## 二、 外贸实战审查与避坑四步法

### 第一步：贸易术语选型与风险分界线核验
按需查阅同级知识库：
- **查 11 种术语对比与 2020 新规** → 读 [references/incoterms-matrix.md](./references/incoterms-matrix.md)

#### 核心研判要点：
1. **风险转移 vs 费用划分分离原则**：
   - CFR/CIF/CPT/CIP 的运费虽然由卖方支付至目的地/目的港，但**货物风险在装运港装上船（或交承运人）时即已转移给买方**！切勿承诺“货到目的港完好无损才算交货”。
2. **CIP 险种新规警惕**：
   - Incoterms 2020 中，**CIP 强制要求卖方投保一切险（ICC A）**，而 CIF 仅维持最低险（ICC C）。报 CIP 时保费率必须相应调高！
3. **EXW 退税风险**：
   - 走正规退税通道的外贸企业，谨慎接 EXW，否则买家自行提货不按卖方抬头报关，将导致**无法退税甚至视同内销补税**；建议改推 **FCA**。

---

### 第二步：DDP 与目的港“倒贴高危预警”排查

如果客户要求报 DDP（Delivered Duty Paid），立即启动倒贴排查：
1. **关税与反倾销税核定**：
   - 是否存在目标国反倾销税（如欧美对特定钢管、铝合金、床垫、橱柜征收的反倾销税可能高达 50%~200%）？
   - 是否涉及特殊附加关税（如美国 301 关税条款）？
2. **增值税 (VAT / GST) 抵扣硬伤**：
   - 卖方在目的国是否有当地注册税号和法人登记（IOR / EORI）？
   - 若无税号，缴纳的 VAT 属于不可抵扣沉没成本，必须全额计入报价！
3. **目的港超期仓储费与滞港费（Demurrage / Detention）**：
   - 目的港海关一旦查验或客户拒付提货，每天按 100~300 美元累计，是否在合同中设立免责与超期止损条款？
4. **决策建议**：
   - 若以上要素无法全部把控，**坚决不报 DDP，主动将报价调整为 DAP（目的地交货，买方自付税金清关）**，并向客户解释清关合规要求。

---

### 第三步：FOB 指定货代“敲竹杠与无单放货”防御
按需查阅同级知识库：
- **查指定货代谈判与维权话术** → 读 [references/forwarder-risk-defense.md](./references/forwarder-risk-defense.md)

#### 核心防守要点：
1. **订舱前锁死起运港费用**：
   - 收到买家指定货代联系方式后，必须要求货代提供**盖章版《起运港费用确认单》**。
   - 杂费超出市场公允标准 30% 以上的，坚决依据合同条款要求买家介入纠偏或由买家补差。
2. **尾款防线与放单控制**：
   - 做 FOB 指定货代，坚决执行**“发货前或凭提单副本结清 100% 货款，见款后方可电放”**原则。
   - 绝不接受买家未付款前先出具“同意电放保函”，谨防无单放货。

---

### 第四步：外贸报价与出口退税精确数学测算
按需查阅同级知识库：
- **查数学公式与港杂费明细** → 读 [references/quotation-formula-sop.md](./references/quotation-formula-sop.md)

#### 核心计算基准：
1. **真实实际采购成本**：
   $$\text{实际成本} = \text{含税采购价} \times \left[ 1 - \frac{\text{退税率}}{1 + \text{增值税率}} \right]$$
2. **FOB 美元底价公式**：
   $$\text{FOB (USD)} = \frac{\text{实际采购成本} + \text{国内综合港杂运费 (RMB)}}{\text{安全结算汇率} \times (1 - \text{销售利润率})}$$
3. **CIF 美元报价公式**：
   $$\text{CIF (USD)} = \frac{\text{FOB (USD)} + \text{海运费 } F}{1 - 1.1 \times \text{保险费率 } r}$$
