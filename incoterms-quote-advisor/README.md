## 📖 技能简介

在国际贸易实战中，许多外贸业务员、跨境卖家或制造工厂常常因为**贸易术语概念模糊**、**退税与成本算错**、**买家指定货代敲竹杠**或**盲目答应 DDP 条款**而陷入巨额亏损甚至货款两空的困境。

**外贸报价与贸易术语防坑助手** 是专为外贸从业者量身打造的实战型风控与精算工具。它融合了国际商会《国际贸易术语解释通则 2020》（Incoterms 2020）法定规则与一线外贸实战经验，帮助用户搞清条款界线、拆解报价公式、拦截货代高额乱收费，守住每一分出口利润。

---

## 🎯 核心功能与实战场景

1. **Incoterms 2020 权责与风险分界线精算**
   - 彻底理清 11 种术语（EXW, FCA, FAS, FOB, CFR, CIF, CPT, CIP, DAP, DPU, DDP）的风险转移点与费用分界点。
   - 重点掌握 2020 新规变化（如 CIP 强制要求投保一切险 ICC A、DAT 改为 DPU、FCA 提单批注机制）。
2. **DDP 倒贴防空警报**
   - 拦截外贸最大“亏损陷阱”：排查目的港反倾销税、惩罚性关税（如美线301）、无海外法人税号（IOR）导致增值税（VAT）无法抵扣等硬伤。
   - 提供安全替代谈判方案（如转报 DAP）。
3. **FOB 指定货代敲竹杠与无单放货防御 SOP**
   - 提供起运港高额杂费（Local Charges）抗辩话术与合同制约条款。
   - 防范货代提单（HBL）无单放货风险，建立尾款收取与放单铁律。
4. **工业级出口报价与退税数学模型**
   - 纠正将退税额直接抵扣含税价的经典错误算法。
   - 提供从出厂价、FOB 美元底价、CIF 到岸价到 DDP 完税价的逐级严谨换算公式，内嵌汇率安全缓冲。
