# 外贸出口报价数学模型与成本测算 SOP

> 绝大多数新手外贸人最大的亏损源头，就是**算错了出口退税**或**遗漏了隐性港杂费**。  
> 本手册提供经得起财务审计的工业级报价换算公式。

---

## 一、 出口退税真实成本与测算误区

### 1. 致命误区：把退税额直接当成利润扣减
- **典型错误算法**：
  $$\text{错误成本} = \text{含税采购价} \times (1 - \text{退税率}) \quad \text{【严重算错！】}$$
  - *例如*：含税进价 113 元，增值税率 13%，退税率 13%。  
    若按错误算法：$113 \times (1 - 13\%) = 98.31$ 元。  
  - *真实情况*：退税额是依据**不含税价**计算的！  
    不含税价 $= 113 / (1 + 13\%) = 100$ 元；  
    退税额 $= 100 \times 13\% = 13$ 元；  
    **真实实际采购成本** $= 113 - 13 = 100$ 元！  
    按错误算法少算了 1.69 元，上万件订单少算几万元利润！

### 2. 标准实际采购成本公式
$$\text{不含税采购价} = \frac{\text{含税采购价}}{1 + \text{增值税征税率}}$$

$$\text{应得退税额} = \text{不含税采购价} \times \text{出口退税率} = \frac{\text{含税采购价}}{1 + \text{增值税征税率}} \times \text{出口退税率}$$

$$\text{真实实际采购成本} = \text{含税采购价} - \text{应得退税额} = \text{含税采购价} \times \left[ 1 - \frac{\text{出口退税率}}{1 + \text{增值税征税率}} \right]$$

> **征退税率一致时（如征 13% 退 13%）**：  
> 真实实际采购成本 = 不含税采购价。  
> **征退税率不一致时（征税率高于退税率，如征 13% 退 9%）**：  
> 差额 $13\% - 9\% = 4\%$ 为“不可退税计入成本额”，必须并入实际成本中！

## 二、 逐级报价测算公式（EXW → FOB → CIF → DDP）

### 1. FOB (离岸价，USD) 计算模型
FOB 卖方需承担：实际货物采购成本 + 国内工厂至码头运费 + 起运港口杂费 + 报关代理费 + 预期企业利润，并按汇率折算为美元。

$$\text{FOB (USD)} = \frac{\text{实际采购成本} + \text{国内综合港杂运费 (RMB)}}{\text{汇率} \times (1 - \text{销售利润率})}$$

- **公式参数详解**：
  - **国内综合港杂运费 (RMB)**：内陆拖车费 + 码头操作费(THC) + 订舱费 + 报关费 + 单证及EDI费 + 查验预备金分摊。
  - **销售利润率**：以销售额（FOB价）为基准的毛利率。例如预期 15% 利润，即分母乘 $(1 - 0.15)$。
  - **安全结汇汇率**：由于收汇存在 30~90 天账期，建议汇率在当前即期汇率基础上扣减 1%~2% 避险缓冲（例如当前汇率 7.25，建议测算汇率取 7.15）。

---

### 2. CIF (到岸价，USD) 计算模型
CIF 卖方需在 FOB 基础上增加：目的港海运费 (Ocean Freight) + 海运货物运输保险费 (Marine Cargo Insurance)。

- 国际常规加成投保比例通常为 **110%**（发票金额的 1.1 倍）。
- 设海运费为 $F$ (USD)，保险费率为 $r$（通常 ICC(C) 险约为 0.1%~0.2%）：

$$\text{保费} = \text{CIF} \times 1.1 \times r$$

$$\text{CIF} = \text{FOB} + F + \text{CIF} \times 1.1 \times r$$

$$\text{CIF (USD)} = \frac{\text{FOB (USD)} + \text{海运费 } F}{1 - 1.1 \times \text{保险费率 } r}$$

---

### 3. CFR (成本加运费，USD) 计算模型
$$\text{CFR (USD)} = \text{FOB (USD)} + \text{海运费 } F$$

---

### 4. DDP (完税后交货，USD) 计算模型与高危防线
DDP 是对出口方风险极大的术语，必须将目的港全部不可控税费计入：

$$\text{DDP} = \text{CIF} + \text{目的港码头操作杂费(DTHC/Port Charges)} + \text{目的港清关费} + \text{目的国关税} + \text{反倾销税/附加关税} + \text{目的国增值税(VAT/GST)} + \text{末端派送内陆运费}$$

> ⚠️ **超儿哥哥关键警报**：
> 1. **增值税 (VAT) 倒贴**：在欧洲或英国做 DDP，买方如果是本土企业，通常要求 VAT 发票抵扣。若出口方无当地 VAT 号，增值税不可抵扣，这笔 19%~21% 的税款直接由卖方承担，吞噬全部利润！
> 2. **关税核定风险**：目的港海关若重新审定完税价格或要求补充原产地证，可能按更高标准征税。
> 3. **目的港超期费 (Demurrage / Detention)**：一旦买方拖延提货或清关遇阻，免堆期过后按天收取巨额滞港费（美线常见每日 100~300 美元/柜）。

## 三、 出口起运港常见杂费（Local Charges）测算参考

以中国主要港口（深圳、宁波、上海、青岛）整箱（FCL）常规货代收费基准参考：

| 费用项目 | 英文简称 | 计费单位 | 常见参考区间 (RMB) | 备注 |
|---|---|---|---|---|
| **码头操作费** | THC / ORC | 每柜 | 20GP 约 700~900；40GP/HQ 约 1100~1400 | 船公司码头刚性费用 |
| **订舱服务费** | Booking Fee | 每柜/每票 | 200 ~ 500 元 | 货代操作费 |
| **港口安全设施费** | ISPS | 每柜 | 10 ~ 30 元 | 码头安保费 |
| **报关费** | Customs Clearance | 每票 | 100 ~ 200 元 | 含单证录入，多于5项加收换页费 |
| **提单电放/签发费** | B/L Fee / Telex Release | 每票 | 300 ~ 500 元 | 正本提单或电放保函处理费 |
| **文件传输及舱单录入** | EDI / AMS / ENS | 每票 | 100 ~ 300 元 | 欧美线有 AMS/ENS 强制申报费 |
| **内陆集卡拖车费** | Trucking Fee | 每柜 | 视工厂距离码头而定（800~3500元） | 工厂装箱至码头运费 |
| **海关查验预备金** | Inspection Buffer | 每票 | 均摊 200~500 元 | 机检查验或人工掏箱查验防险金 |

## 四、 客户索要 DDP 报价时的“避险决策清单”

当外贸客户提出“Please quote DDP”时，按以下决策树应对：

```
客户要求 DDP 报价
    │
    ├─► 1. 确认目标国是否有官方/合规清关代理和税号？
    │       ├─ 否 ──► 坚决拒绝 DDP，主动改推 DAP 或 CIF。
    │       │         理由话术："Due to import customs clearance regulations, we recommend DAP."
    │       └─ 是 ──► 进入第 2 步
    │
    ├─► 2. 核实目的国商品 HS 编码、关税率及反倾销税？
    │       ├─ 存在反倾销税或不确定性 ──► 坚决不包关税，改报 DAP。
    │       └─ 关税税率明确透明 ──► 进入第 3 步
    │
    └─► 3. 目的港增值税 (VAT) 谁承担？
            ├─ 买方具有自主清关税号 ──► 报 DAP + 由买方自付税金清关
            └─ 必须双清包税 (DDP) ──► 必须找可提供全包正规运单的优质物流，在报价中加收 15% 风险溢价
```
